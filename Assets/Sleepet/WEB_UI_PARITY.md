# 前端字体、动态效果和跨场景对齐修复

本轮基准是本地 `Sleepet-Unity/Sleepet` 的 CSS 和 JavaScript。源前端保持只读。

## 字体

所有 20 个 Scene 的原生 Text 改用项目内的 Arial 字体文件，保留粗体和斜体。它对应当前 Windows 上前端 CSS 的实际回退字体；机器没有安装 PingFang SC/TC，前端也没有附带对应字体文件。因此本轮不声称还原了 Figma 导出图片中烘焙的苹方字形。

字体资源：`Art/Fonts`。它们随项目导入，不依赖目标电脑是否安装 Arial。账号、步骤标题、字段与说明文字同时按前端调整字号、字重和颜色。

## 动态效果

- `Tools/ImportWebMotion.cjs` 从源 CSS 提取开屏的 16 条关键帧轨道，保存为 `Art/Flow/web-motion.json`；`SleepetSplashMotion` 播放共享的 4 秒时间线，包括图标、七个字母和账号表单进入。
- 创建页：800ms 加载点与宠物透明度循环，1.6 秒进入确认页。
- 晨间页面：按 CSS 的逐项延迟入场，淡入并向上移动 12 个设计像素。布局外层和运动内层分离，避免动画覆盖底部锚点。
- 评分：7 秒交替漂浮；遮罩及亮度按前端五档值，用 450ms 渐变；光带用 550ms 渐变，并随玻璃球一起运动、裁切。
- 喝水：水杯按前端裁切，5 秒交替摇摆 ±2°；保留 0.75 倍速宠物动画。
- 拉伸：保留真实五分钟计时，补回圆环端点；按前端时序进入。
- 待办：标题、时间线、卡片、宠物、通知及按钮分批进入。
- 结束：双上箭头 2 秒提示循环，圆形扩散使用前端缓动；跨 Scene 保留短暂淡出，避免切换瞬间消失。

原生 UI 渐变图层、描边和阴影仍使用 Unity 渲染；不将这些修复等同于浏览器逐像素一致或全部 CSS backdrop-filter 的复现。

## 底部位置

- 旧页面与新流程统一使用 402×874 设计坐标。长手机按宽度缩放并延长画布；较宽或较短的窗口按高度容纳完整画板，水平居中。
- 新页面的底部按钮和辅助链接按前端的底部距离锚定。注册主按钮底距 97，晨间 Done 底距 99，待办按钮底距 81。
- 导航栏背景向安全区延伸一次，不再同时把整个栏向上重复移动。
- Home、Me、Weekly、Daily、DayDetail 的导航槽、透明点击区域与图标中心统一。点击区域保留 112×56。
- Scene 中保留原生可编辑对象、数据绑定和按钮事件。新增 `SleepetFlowLayout` 的 footers 可在 Inspector 调整；`Motion visual` 为动画内层，外层 RectTransform 负责位置。
